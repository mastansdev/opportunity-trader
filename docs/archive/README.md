# Archive

Dated, one-off snapshots from the 23 July – 5 August 2026 build sprint --
audits, daily task lists, "what to run tomorrow" notes, post-market
recaps. Each was accurate for the session it was written for and most
are superseded by a later one in this same folder, or by the live
state of the code.

Moved here 12 August 2026 during an end-to-end review, after the
operator flagged that too many of these had accumulated loose in the
repo root with no way to tell which were still current. None of these
files are read by any code -- moving them changes nothing about how
the bot runs.

`RAILWAY_DEPLOY.md` is here for a different reason: it documents a
cloud news-engine (`run_news_engine.py`, `news_bot/`) that no longer
exists in this codebase at all. Kept for history, not as a guide --
do not follow its setup steps.

For current, living documentation see the repo root: `README.md`,
`PHASES.md`, `RULE_BOOK.md`, `TRADING_POLICY.md`, `DAILY_ROUTINE.md`,
`RUN_SCHEDULE.md`, and `config.py` itself (which doubles as this
project's dated decision log).
